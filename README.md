## Как посмотреть, не сломав своё

Склонировать этот репозиторий в ОТДЕЛЬНУЮ папку — не внутрь папки своего проекта:

```bash
git clone https://github.com/claude-code-kurs/radar-zayavok.git
```

Затем переключиться на нужную ветку там же, например:

```bash
git checkout lesson-06-solution
```

Свой репозиторий это не меняет.

## Это не стартовый шаблон
