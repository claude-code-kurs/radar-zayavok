# Радар заявок — эталонный проект курса

Эталонный проект живёт отдельным публичным репозиторием — https://github.com/claude-code-kurs/radar-zayavok, ветка на урок (`lesson-NN-solution`). Здесь, в курсовом репозитории, — только этот README, для быстрой сверки, какой урок до какого состояния доведён; сам код смотреть и клонировать — по ссылке выше.

## Урок → ветка

| Урок | Ветка | Результат к концу урока |
|---|---|---|
| 1 | `lesson-01-solution` | Статичная визитка, первый коммит и push на GitHub |
| 2 | `lesson-02-solution` | CLAUDE.md и ARCHITECTURE.md в проекте |
| 3 | `lesson-03-solution` | Визитка на FastAPI и шаблонах Jinja, сервер запускается своей командой |
| 4 | `lesson-04-solution` | Лента кабинета работает на тестовых заявках |
| 5 | `lesson-05-solution` | Юзербот читает один чат без вступления, выводит сообщения в консоль |
| 6 | `lesson-06-solution` | Несколько источников, отсев по ключевым словам, защита от повторов в три уровня — лента оживает на настоящих данных |
| 7 | `lesson-07-solution` | Дешёвый слой отсева, классификатор на модели, сверка с ручной разметкой |
| 8 | `lesson-08-solution` | Статусы заявок, фильтры и поиск, настройки источников и ключевых слов в кабинете, форма заявки на визитке, статистика |
| 9 | `lesson-09-solution` | Сайт и кабинет открываются по адресу в интернете |
| 10 | `lesson-10-solution` | Юзербот работает на сервере круглосуточно и сообщает о находках |
| 11 | `lesson-11-solution` | Кейс на визитке, готовая упаковка для продажи |

Урок 0 — подготовка окружения, без кода; отдельной ветки под него нет. Эталон собран целиком, от нулевого урока до одиннадцатого.

## Как посмотреть, не сломав своё

Склонировать этот репозиторий в ОТДЕЛЬНУЮ папку — не внутрь папки своего проекта:

```bash
git clone https://github.com/claude-code-kurs/radar-zayavok.git
```

Затем переключиться на нужную ветку там же, например:

```bash
git checkout lesson-06-solution
```

Свой репозиторий это не меняет.

## Это не стартовый шаблон

Не копируйте код отсюда в свой проект. Смысл курса — собрать это самому с агентом, на своей нише. Сюда — только сверяться.
