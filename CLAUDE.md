# CLAUDE.md

Правила этого проекта. Читать в начале работы, до первой правки файлов.

## Что за проект

Радар заявок: сайт-визитка, закрытый кабинет со лентой заявок, юзербот, который читает
Telegram-группы, и база, куда всё это складывается.

## Стек

- Python
- FastAPI — сервер
- Jinja — шаблоны страниц
- SQLite — база
- HTMX — интерактивность на фронте
- python-dotenv — чтение секретов из `.env` (урок 4)
- python-multipart — формы, без него FastAPI не принимает форму входа (урок 4)
- Telethon — юзербот, который читает Telegram (урок 5)
- Без React
- Без Docker

Новые библиотеки и фреймворки сверх этого списка — только с моего согласия.

## Как называть файлы и папки

- Файлы и папки — строчными латинскими буквами, слова через нижнее подчёркивание:
  `main.py`, `templates/`, `static/`.
- Шаблоны страниц — в `templates/`, стили и картинки — в `static/`.
- Точка входа сервера — `main.py` в корне проекта.
- Документы проекта — в корне, заглавными: `CLAUDE.md`, `ARCHITECTURE.md`.

## Правила работы с агентом

Базовые правила из `agent-rules.md` — тот файл остаётся в проекте справочником,
а здесь то, чего придерживаемся в этом проекте.

- Push и команды на сервере делаю только я. Сам их не запускай и не предлагай запустить
  вместо меня.
- Сначала план — потом код. Не начинай писать код, пока я не подтвердил план.
- Секреты только в `.env`, в код и в чат они не попадают.
- Новые библиотеки и фреймворки сверх стека — только с моего согласия.
- Тесты гоняешь только на то, что менял в текущей задаче, не весь набор.
- Чего не проверил — пишешь «не проверено». Не додумывай и не отвечай «готово»,
  если результат не проверен.
